# cloudmem (Gestão)

Memória de longo prazo entre sessões em `MEMORY.md` na raiz do projeto.

## Como fazer
1. Leia `MEMORY.md` se existir.
2. Ao aprender regra central/decisão, adicione uma linha datada.
3. Remova itens obsoletos quando o escopo mudar.
4. Nunca salve segredos.

## Não fazer
- Deixar memória antiga ativa após mudanças drásticas no escopo.

## Quando usar
- Projetos longos onde a IA precisa lembrar regras centrais.
