# career-ops (Pesquisa)

Mapeia mercado, gaps de skills no currículo e simula entrevistas técnicas.

## Como fazer
1. Peça currículo e vaga/área alvo.
2. Compare e liste gaps priorizados com plano de estudo.
3. Simule entrevista: uma pergunta por vez, feedback após cada resposta.
4. Lembre que o caminho padrão não serve para nichos novos.

## Não fazer
- Seguir cegamente se quiser um nicho inovador.

## Quando usar
- Mapear gaps de skills ou se preparar para entrevistas.
