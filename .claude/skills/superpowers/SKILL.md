# superpowers (Programação)

Esteira completa de desenvolvimento: brainstorm → plano → implementação → revisão rígida.

## Como fazer
1. Faça perguntas para fechar requisitos antes de codar.
2. Escreva um plano numerado com arquivos afetados e critérios de aceite; peça aprovação.
3. Implemente em passos pequenos com teste para cada um.
4. Ao final, revise o diff contra o plano e liste desvios.

## Não fazer
- Projetos pequenos ou tarefas rápidas.

## Quando usar
- Quando precisar de arquitetura e revisão rígidas.
