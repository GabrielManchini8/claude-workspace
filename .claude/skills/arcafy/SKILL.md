# arcafy (Design)

Estrutura design system: pastas, tokens e config Tailwind.

## Como fazer
1. Crie `tokens/` (cores, tipografia, espaçamento, raios).
2. Mapeie tokens no `tailwind.config`.
3. Organize `components/` por primitivos e compostos.
4. Documente uso em README.

## Não fazer
- Engessar o design na fase de brainstorm.

## Quando usar
- Criar design systems reutilizáveis.
