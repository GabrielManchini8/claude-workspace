# dstack (Gestão)

Orquestra ambientes isolados (dstack/Docker) para testes pesados, Data Science e IA.

## Como fazer
1. Verifique se o usuário conhece YAML/Docker; explique se não.
2. Gere `.dstack.yml` (task/service/dev-environment) com recursos (GPU, memória).
3. Mostre os comandos `dstack apply` e como acompanhar.
4. Avise sobre custos de nuvem.

## Não fazer
- Usar sem conhecimento prévio de infraestrutura.

## Quando usar
- Pipelines complexos de Data Science e IA.
