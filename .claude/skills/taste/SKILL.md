# taste (Design)

Refina estética: paletas, tipografia e efeitos CSS modernos.

## Como fazer
1. Leia as diretrizes estéticas já definidas e mantenha-as.
2. Proponha 2–3 combinações de paleta + fontes.
3. Entregue tokens CSS e ajustes finos (espaçamento, sombras, transições).
4. Registre a escolha para não mudar entre sessões.

## Não fazer
- Mudar diretrizes estéticas no meio do desenvolvimento.

## Quando usar
- Refinar o visual fino.
