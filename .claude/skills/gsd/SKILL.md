# gsd (Gestão)

Get Shit Done: execução ultra-pragmática passo a passo.

## Como fazer
1. Defina o menor resultado funcional.
2. Execute um passo por vez, sem polimento.
3. Marque débito técnico com `TODO(gsd)`.
4. Ao final, liste os TODOs para revisão.

## Não fazer
- Usar continuamente sem revisão de arquitetura.

## Quando usar
- Quebrar procrastinação e entregar algo funcional rápido.
