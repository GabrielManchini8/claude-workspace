# agent-skills (Programação)

Execução autônoma em ecossistemas fechados (.NET, etc): testes especializados, análise de logs.

## Como fazer
1. Confirme o escopo e os comandos permitidos antes de começar.
2. Nunca rode comandos destrutivos (rm -rf, drop, force push) sem confirmação.
3. Rode testes/ferramentas e registre saída real; não invente resultados.
4. Resuma achados com evidência.

## Não fazer
- Rodar sem prompts restritivos ou travas de ambiente.

## Quando usar
- Testes especializados ou análise de logs binários.
