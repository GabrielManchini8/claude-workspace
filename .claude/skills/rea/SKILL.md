# rea (Pesquisa)

Auditoria pesada: checagem de fatos e extração de dados limpos de fontes caóticas.

## Como fazer
1. Extraia cada afirmação/dado em tabela.
2. Para cada um: fonte, trecho exato, status (confirmado/contradito/sem fonte).
3. Normalize tabelas extraídas (CSV/Markdown).
4. Seja exaustivo; não é para respostas rápidas.

## Não fazer
- Pedir execução imediata ou respostas rápidas.

## Quando usar
- Checagem de fatos e extração de tabelas.
