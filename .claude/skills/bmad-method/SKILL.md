# bmad-method (Gestão)

Divide projetos grandes em papéis: Analista, PM, Arquiteto, Scrum Master, Dev, QA.

## Como fazer
1. Analista: brief do problema.
2. PM: PRD com histórias de usuário.
3. Arquiteto: arquitetura e stack.
4. SM: quebra em histórias pequenas; Dev implementa; QA valida.

## Não fazer
- Corrigir uma linha de CSS ou bugs triviais.

## Quando usar
- Planejar projetos volumosos e sistemas corporativos.
