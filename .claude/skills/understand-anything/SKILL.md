# understand-anything (Pesquisa)

Decompõe conceitos, código legado ou papers densos em resumos multinível.

## Como fazer
1. Resumo em 1 frase.
2. Resumo em 1 parágrafo.
3. Explicação detalhada por partes, com analogias.
4. Liste o que precisa ser validado no código/fonte real.

## Não fazer
- Aceitar explicações sem validar o código real.

## Quando usar
- Ler código legado caótico ou papers densos.
