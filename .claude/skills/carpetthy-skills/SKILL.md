# carpetthy-skills (Programação)

Automatiza infraestrutura periférica: Dockerfile, docker-compose, scripts de build, CI.

## Como fazer
1. Detecte stack e versões do projeto.
2. Gere Dockerfile/compose/CI mínimos e comentados.
3. Explique cada decisão para não virar caixa-preta.
4. Nunca altere infra de produção sem revisão humana.

## Não fazer
- Configurar infraestrutura crítica sem revisão.

## Quando usar
- Setups iniciais rápidos de ambiente de desenvolvimento.
