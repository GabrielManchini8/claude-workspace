# agent-reach (Pesquisa)

Buscas paralelas em web, APIs e bases, consolidando várias fontes.

## Como fazer
1. Quebre a pergunta em sub-perguntas.
2. Pesquise em paralelo (subagentes/WebSearch).
3. Consolide com citação de fonte para cada afirmação e marque conflitos.
4. Não envie dados confidenciais para serviços externos.

## Não fazer
- Usar com informações confidenciais.

## Quando usar
- Quando a resposta depende de várias fontes externas.
